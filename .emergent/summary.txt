<analysis>**original_problem_statement:**
The user wants to build a QR menu management system for cafes and restaurants.

**PRODUCT REQUIREMENTS:**
- **Core Functionality:** Businesses should be able to create an admin account, build a menu by adding categories and products (with names, descriptions, prices). The menu should be accessible via a QR code and update in real-time.
- **Admin Panel Features:**
    - Each business has its own separate admin panel.
    - **Customization:**
        - Light and dark theme options.
        - Ability to upload a business logo and a hero image for the public menu.
        - Ability to customize the colors of category and product text/backgrounds.
        - Add a business Instagram link to the public menu.
    - **Product Management:**
        - Upload product photos.
        - Toggle product availability.
        - Add campaign products, which can be shown in a special Campaigns category or exclusively there.
    - **User Account Management:** Users should be able to change their password and request account deletion.
- **Public Menu Features:**
    - Display a campaign popup with an image and description if a campaign is active.
    - A dedicated Campaigns category for special offers.
    - A search bar at the top to search for products across all categories.
    - PWA Add to Home Screen functionality.
- **Subscription & Monetization:**
    - A 7-day trial for new sign-ups.
    - A single yearly subscription plan is required after the trial.
    - A pluggable payment system to accommodate Turkish providers like PayTR.
    - A manual license activation system for the super admin.
- **Super Admin Functionality:**
    - A private, mobile-responsive dashboard to:
        - View a list of all registered businesses with filtering by status (Trial, Active, Expired).
        - Register new businesses manually with an option for a trial or a 1-year license.
        - Add a 1-year license to any existing business directly from the list.
        - View and approve account deletion requests from users.

**User's preferred language**: Turkish
