<analysis>**original_problem_statement:**
The user wants to build a QR menu management system for cafes and restaurants.

**PRODUCT REQUIREMENTS:**
- **Core Functionality:** Businesses should be able to create an admin account, build a menu by adding categories and products (with names, descriptions, prices). The menu should be accessible via a QR code and update in real-time.
- **Admin Panel Features:**
    - Each business has its own separate admin panel.
    - **Customization:**
        - Light and dark theme options for the panel.
        - Ability to upload a business logo and a hero image for the public menu.
        - Ability to customize the colors of category and product text/backgrounds, with a bulk update option.
        - Add a business Instagram link to the public menu.
    - **Product Management:**
        - Upload product photos (as files: jpg, jpeg, png), which should appear as squares to the left of the product info on both the admin panel and public menu.
        - Toggle product availability (on/off for sale) directly from the dashboard product list.
- **Subscription & Monetization:**
    - A 7-day trial for new sign-ups.
    - A single yearly subscription plan is required after the trial.
    - An online payment system is needed. The user initially requested Stripe but is now asking for a system that can accommodate other Turkish payment providers.
    - A manual license activation system for the super admin to handle in-person sales.
- **Super Admin Functionality:**
    - A super admin role for the system owner.
    - This super admin should have a private dashboard to:
        - View a list of all registered businesses (name, email, phone).
        - Register new businesses manually.
        - Access the manual license activation feature (which should be hidden from regular business users).
- **UI/UX:**
    - The admin panel must be mobile-responsive.
    - Don't log the user out after they update their profile.
    - On the public menu, if a logo is present, hide the business name.

**User's preferred language**: Turkish

A basic subscription model with a 7-day trial and a yearly plan is in place, with non-functional Stripe integration. The admin panel is mobile-responsive.
